# ADR 0019. Личный список аллергенов

**Статус** Принято

**Дата** 2026-11-24

## Контекст

При подготовке к приёму врачу и пациенту нужен быстрый доступ к списку известных аллергенов рядом с лекарствами. Для первой версии достаточно названия, которое вводит пользователь.

## Решение

- Модель `Allergy` хранится в отдельном приложении Django с привязкой к владельцу. `GET /api/allergies/` возвращает личный список от новых записей к старым. `POST /api/allergies/` добавляет название длиной до 160 символов.
- Храним название для отображения и отдельный ключ без учёта регистра и лишних пробелов. Ограничение уникальности в базе защищает от повторов в одном аккаунте при одновременной отправке.
- Экран `/allergies` размещён рядом с «Лекарствами» и состоит из поля добавления и списка. Команда `transfer_archive` переносит аллергены вместе с другими данными выбранного владельца.

## Последствия

Список можно развивать независимо от документов и приёма лекарств. Текущий интерфейс поддерживает добавление и просмотр со слов пользователя. [История лекарств](0010-medication-history.md) · [Перенос архива](0013-archive-transfer.md)
