# ADR 0011. Мобильная PWA

**Статус — принято.** 23 ноября 2026 года.

## Контекст

Anamnes используется через браузер на компьютере и телефоне. PDF, результаты поиска и сведения о лекарствах относятся к частному архиву.

## Решение

- На узком экране навигация становится горизонтальной, формы и записи помещаются в одну колонку, а просмотрщики сравнения располагаются друг под другом.
- Корневой элемент приложения и офлайн-страницы задаёт `overscroll-behavior-y: none` для вертикального отскока на краях страницы. Экран входа и экран загрузки используют минимальную высоту `100svh`, которая учитывает развёрнутые панели браузера. [Поддержка прокрутки в Safari 16.4](https://webkit.org/blog/13966/webkit-features-in-safari-16-4/#scrolling) · [Единицы высоты в Safari](https://webkit.org/blog/12445/new-webkit-features-in-safari-15-4/)
- Браузер устанавливает приложение по веб-манифесту. Для запуска на телефоне используется HTTPS, для локальной проверки подходит loopback. Service worker производственной сборки сохраняет только общую страницу состояния сети.
- Запросы к API идут по сети с проверкой сессии. Сервис-воркер пропускает API и PDF, а офлайн-навигация открывает только общую страницу.
- В Docker наружу опубликован loopback-порт. При доступе через HTTPS используется доверенный прокси на том же хосте, который передаёт имя хоста и схему HTTPS.

## Последствия

Медицинские записи доступны при подключении к серверу. Можно открыть установленную PWA и получить понятное сообщение, если связь пропала.

[Установка PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable) · [Service workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)
