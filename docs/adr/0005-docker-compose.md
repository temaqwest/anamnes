# ADR 0005. Изолированная сборка и запуск в Docker Compose

**Статус — принято.** 23 ноября 2026 года.

## Контекст

Anamnes должен запускаться на машине с Docker Compose без установки Python, Node.js и PostgreSQL на хост. При обновлениях нужно сохранять базу и исходные PDF.

## Решение

- Сборка фронтенда использует `npm ci` и lockfile внутри образа Node.js. Готовые файлы переносим в образ Nginx. Nginx отдаёт браузерный клиент и проксирует `/api/` на Gunicorn.
- API, миграции и обработчик документов используют общий Python-образ с зафиксированными зависимостями. Compose ждёт готовности PostgreSQL и завершения миграций перед запуском API и обработчика.
- Сборка использует отдельные контексты `backend` и `frontend`. Правила `.dockerignore` ограничивают их исходным кодом и файлами сборки. Секреты передаются на запуске через `.env`.
- PostgreSQL и оригиналы PDF хранятся в двух именованных томах. Обработчик монтирует том оригиналов для чтения. Наружу опубликован порт Nginx на `127.0.0.1`.

## Последствия

- После правок образ можно пересобрать через `docker compose up --build -d`. Обычная остановка проекта сохраняет данные. Резервное копирование включает и БД, и оригиналы.
- Установка через Compose создаёт свой архив в PostgreSQL. Перенос существующего архива SQLite требует переноса записей базы и файлов оригиналов.
- Конфигурация с HTTP рассчитана на доступ по loopback. Публичный доступ потребует HTTPS и отдельной настройки.
