# ADR 0020. Предупреждение о совпадении имён PDF

**Статус** Принято

**Дата** 2026-11-24

## Контекст

При пакетной загрузке легко повторно выбрать файл, который уже есть в личном архиве. Клиника может выдавать разные PDF с одинаковым именем, поэтому решение о сохранении принимает пользователь.

## Решение

- `POST /api/documents/suggestions/` возвращает `is_duplicate` для каждого файла вместе с предложенными метаданными. API сравнивает исходное имя целиком, включая расширение, регистр и пробелы, с именами сохранённых документов текущего владельца.
- Один запрос проверяет всю пачку в базе по составному индексу `owner, original_name`. Клиент получает флаг для каждой карточки и показывает текстовое предупреждение с цветовым акцентом.
- Сохранение остаётся доступным при совпадении. Флаг отражает состояние архива на момент получения подсказок.

## Последствия

Проверка использует только имена сохранённых файлов. Для сравнения содержимого или проверки файлов только внутри текущей пачки понадобится отдельное правило. [Импорт PDF](0003-pdf-import.md) · [Подсказки по имени PDF](0018-filename-area-suggestions.md)
