## Как добавить решение

1. Создайте файл `NNNN-короткое-название.md` со следующим номером и добавьте его в таблицу.
2. Укажите статус и дату, затем опишите контекст, решение и последствия. Если выбор обсуждается, используйте статус «Предложено» и опишите варианты, которые реально рассматривались.
3. При пересмотре принятого решения заведите новый ADR. Свяжите записи в обе стороны и пометьте старую как «Заменено».

Записывайте решения, которые влияют на структуру кода, API, данные, доступ или инфраструктуру. ADR удобно обновлять вместе с изменением, которое реализует решение.
