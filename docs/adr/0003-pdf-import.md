# ADR 0003. Импорт и сохранение оригиналов PDF

**Статус — принято.** 23 ноября 2026 года.

## Контекст

В большинстве имён дата и название процедуры разделены `_`. В архиве также встречаются файлы без даты, а указанная в имени дата может расходиться с реальной. При пакетной загрузке файлы могут сохраниться частично.

## Решение

- Перед сохранением API предлагает дату и название из исходного имени. Форма показывает это имя рядом с редактируемыми полями. При неоднозначной или некорректной дате поле даты остаётся пустым. Для сохранения нужны дата и название.
- Оригинал, исходное имя и подтверждённые метаданные хранятся раздельно. Сортировка использует подтверждённую дату исследования. Привязка к областям допускает несколько значений.
- Одна форма принимает до 10 PDF. Каждый файл сохраняется отдельным запросом и получает собственный статус. Ключ загрузки привязан к владельцу и предотвращает создание дубликата при повторе того же запроса.

## Последствия

- Пользователь может исправить метаданные после загрузки, сохраняя исходный PDF и исходное имя. При ошибке можно повторить загрузку выбранного файла.
- Новый шаблон имени проверяем на обезличенном примере. Если суффикс или дата распознаны неоднозначно, пользователь может подтвердить нужные значения вручную.
