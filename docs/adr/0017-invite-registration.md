# ADR 0017. Регистрация по приглашениям

**Статус** Принято  
**Дата** 2026-11-24

## Контекст

Anamnes должен принимать новых пользователей и сохранять изоляцию их архивов. Существующие аккаунты и связи с архивами опираются на встроенную модель пользователя Django.

## Решение

- Приложение `accounts` ведёт регистрацию по одноразовым приглашениям, связанным с конкретным email. В базе хранится хеш приглашения. Аккаунт становится активным после подтверждения адреса.
- `AccountEmail` связывает уникальный нормализованный адрес с существующей моделью пользователя. Вход использует сессии Django, новые пользователи вводят подтверждённый email. Старые аккаунты также могут входить под своим именем пользователя.
- Письма содержат одноразовые ссылки. Сброс пароля использует генератор токенов Django и отзывает прежние сессии через смену хеша пароля. Токены ссылок передаются через фрагмент адреса и обрабатываются после действия пользователя.
- Отправка писем и попытки входа ограничены на уровне базы. Режим регистрации переключается через `ANAMNES_SIGNUP_ENABLED`, в Compose он выключен по умолчанию. Локально письма выводятся в консоль, для публичной среды настраивается SMTP.
- Перенос архива включает подтверждённые адреса и состояния подтверждения. Приглашения, счётчики попыток и браузерные сессии создаются заново в целевой среде.

## Последствия

Перед публичным запуском нужно проверить ограничения на доверенном HTTPS-прокси, настроить фоновую доставку почты, проверить восстановление резервной копии и зафиксировать правила хранения и удаления данных. Восстановление пароля доступно аккаунтам с подтверждённым адресом.
