# ADR 0001. Стек приложения и хранение данных

**Статус — принято.** 23 ноября 2026 года.

## Контекст

Anamnes хранит личные медицинские документы и помогает быстро открыть их на приёме. Первая версия рассчитана на настольные браузеры. Веб-клиент впоследствии будет использоваться на телефонах как PWA.

## Решение

- Веб-клиент строим на React, TypeScript и Vite. UI-компоненты берём из shadcn/ui, PDF отображаем через PDF.js.
- API реализуем на Django и Django REST Framework. Клиент и API работают с одного origin. Для входа используем сессии Django и CSRF-защиту запросов, которые меняют состояние.
- Для развёртывания используем PostgreSQL. Локальный запуск по умолчанию работает на SQLite. Исходные PDF храним отдельно от метаданных в закрытом файловом хранилище и выдаём через API с проверкой владельца.

## Последствия

- Один браузерный клиент покрывает веб и PWA. Адаптацию и проверку на телефонах планируем отдельным этапом.
- Резервная копия архива включает БД и оригиналы. Извлечённый текст и поисковые результаты требуют той же проверки доступа, что и исходные документы.
- Поиск внутри PDF и обработка сканов потребуют отдельного решения о фоновой обработке и индексировании.
