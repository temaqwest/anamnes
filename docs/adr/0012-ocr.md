# ADR 0012. Локальное распознавание сканов

**Статус — принято.** 23 ноября 2026 года.

## Контекст

Сканы в PDF должны находиться по тексту на той же странице, что и документы со встроенным текстовым слоем. Исходные медицинские документы и распознанный текст хранятся в личном архиве.

## Решение

- Фоновый обработчик извлекает встроенный текст через pypdf. Страницы, на которых текст отсутствует, преобразуются в изображение через Poppler и распознаются в Tesseract с языками `rus+eng`. Обработка выполняется локально. Поиск использует прежнюю постраничную индексацию.
- Обработчик ограничивает размер изображения и время рендеринга и распознавания. PDF и изображение для OCR находятся в закрытом временном каталоге. Обработчик удаляет временные файлы после работы и периодически продлевает захват длительных заданий.
- Если рендеринг или распознавание страницы заканчивается ошибкой, обработчик сохраняет текст остальных страниц, включая результаты предыдущей попытки, и присваивает документу статус `failed`. `--retry-failed` повторяет обработку. Для документов с частичным индексом требуется OCR. Статус `no_text` означает, что доступные способы извлечения не дали текста.

## Запуск

Образ backend содержит `poppler-utils`, `tesseract-ocr`, `tesseract-ocr-eng` и `tesseract-ocr-rus`. Для локального запуска вне Docker установите эти пакеты в Debian или `poppler`, `tesseract` и `tesseract-lang` через Homebrew. Команда `tesseract --list-langs` должна показывать `eng` и `rus`. Если зависимостей OCR нет, обработчик продолжает извлекать встроенный текст.

После установки зависимостей или пересборки backend запустите повторную индексацию. `--retry-no-text` ставит в очередь ранее обработанные документы без текста. `--retry-ready` добавляет готовые документы, чтобы найти сканы внутри смешанных PDF. Флаг `--once` завершает процесс, когда очередь опустеет.

```sh
docker compose exec indexer python manage.py index_documents --retry-no-text --retry-ready --once
```

```sh
.venv/bin/python backend/manage.py index_documents --retry-no-text --retry-ready --once
```
