# ADR 0014. Удаление документов

**Статус** Принято  
**Дата** 2026-11-24

## Контекст

Из архива нужно удалять отдельные документы, результаты текущего поиска и весь набор исследований. На том же списке пользователь выбирает пару PDF для сравнения.

## Решение

Чекбокс в шапке выбирает показанные строки, включая все результаты текущих фильтров. Сравнение доступно при выборе двух документов. Кнопка «Удалить все документы» обращается ко всему архиву владельца. Для каждого вида удаления нужен отдельный подтверждающий клик в диалоге с указанием области действия.

`POST /api/documents/bulk-delete/` принимает непустой список UUID или явный признак удаления всего архива. Сервер ограничивает выборку владельцем текущей сессии. Запросы по списку можно повторять. Связи с предметными областями и страницы индекса удаляются каскадно.

В той же транзакции сервер сохраняет в очередь пути оригиналов, затем удаляет файлы после подтверждения транзакции. Если файловое хранилище временно недоступно, команда `cleanup_deleted_originals` повторяет очистку. Записи об исследованиях к этому моменту уже исключены из архива и поиска.

## Последствия

Удаление необратимо через интерфейс. Архиватор может использовать резервную копию для восстановления. Команда удаления документов отделена от управления предметными областями и лекарствами.
