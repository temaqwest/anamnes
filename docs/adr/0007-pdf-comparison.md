# ADR 0007. Независимое сравнение двух PDF

**Статус — принято.** 23 ноября 2026 года.

## Контекст

На приёме врач выбирает два исследования из архива и переключает каждую панель в пределах текущей подборки. При переходе к соседнему исследованию в одной панели ему нужно сохранить место чтения в другой.

## Решение

- Маршрут `/compare` хранит в адресе `left` и `right`, а также область, запрос поиска и сортировку архива. Подборку загружает существующий API документов. Порядок документов совпадает с архивом.
- Список каждой панели исключает документ из другой панели. Кнопки «Предыдущий документ» и «Следующий документ» работают в том же порядке. Если документ найден по тексту, просмотрщик открывает страницу совпадения.
- Обычный просмотр и сравнение используют один компонент PDF.js в `shared/ui/pdf-page`. Каждая панель владеет своим экземпляром просмотрщика. При смене документа пересоздаётся просмотрщик этой панели, а другая сохраняет страницу, масштаб и прокрутку.

## Последствия

- Обновление страницы восстанавливает пару и фильтры. Позиция чтения панели хранится в текущем экземпляре просмотрщика.
- Если выбранные исследования больше недоступны в подборке, экран предлагает выбрать пару заново в архиве.
