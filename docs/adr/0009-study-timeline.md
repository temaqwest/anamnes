# ADR 0009. Календарный таймлайн исследований

**Статус — принято.** 23 ноября 2026 года.

## Контекст

Врач просматривает исследования выбранной области и переходит из результатов поиска к PDF. Для хронологии уже есть подтверждённая дата каждого исследования.

## Решение

- Переключатель в архиве меняет отображение общей подборки. Область, поисковый запрос, месяц и выбранный день хранятся в адресе страницы.
- Шкала показывает календарные дни выбранного месяца с одинаковым интервалом. Исследования одного дня раскрываются общей точкой. Список и стрелки переключают месяцы с исследованиями из текущей подборки. Левая стрелка ведёт к более раннему месяцу, правая к более позднему.
- Ссылка открывает PDF на странице совпадения, если документ найден по тексту. Возврат из просмотра восстанавливает выбранный день и фильтры.

## Последствия

Хронология строится по существующему API архива. На узком экране календарную шкалу можно прокручивать внутри её области.
