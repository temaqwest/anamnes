# ADR 0018. Предметные области по имени PDF

**Статус** Принято  
**Дата** 2026-11-24

## Контекст

При загрузке пачки PDF пользователь проверяет дату, название и предметные области каждого файла. Названия вроде «ЭКГ» дают явную подсказку для области, а «Анализы» или «МРТ» подходят для разных областей.

## Решение

- Начальный каталог содержит 19 областей. Добавлены акушерство и гинекология, нефрология, урология, оториноларингология, офтальмология, травматология и ортопедия. Стандартное название иммунологии расширено до «Аллергология и иммунология».
- Личная область может ссылаться на стандартную через `StudyArea.preset`. Миграция переиспользует подходящую личную запись с её идентификатором и связями. Словарь использует стандартные идентификаторы, API возвращает идентификаторы личных областей владельца.
- `POST /api/documents/suggestions/` вместе с датой и названием возвращает `area_suggestions` для каждого файла. Словарь распознаёт целые слова и фразы из имени на сервере. Однозначные совпадения отмечаются в черновике, неоднозначные показываются как варианты. Интерфейс показывает найденную фразу.
- Пользователь может снять или добавить любую отметку. Сервер сохраняет области из подтверждённого черновика при загрузке PDF.

## Последствия

Новые правила добавляются в словарь и проверяются на примерах имён. Редактирование названия вручную сохраняет выбор областей в черновике. [Личные области и подсказки](0016-study-area-descriptions.md)
