# ADR 0016. Подсказки предметных областей

**Статус** Принято  
**Дата** 2026-11-24

## Контекст

Начальный список областей должен охватывать больше специальностей. Краткое пояснение помогает выбрать подходящую область при фильтрации и загрузке.

## Решение

Общий каталог и личные области содержат необязательное поле `description` длиной до 300 символов. При первом открытии архива названия и пояснения копируются в личный список. Владелец может изменить или очистить пояснение вместе с названием либо отдельным запросом API.

Миграция добавляет отсутствующие специальности в уже созданные списки. Если имя уже есть с учётом регистра и пробелов, используется существующая область. Переименованные области сохраняют свои названия и идентификаторы. Связи с исследованиями остаются на этих идентификаторах.

## Последствия

Интерфейс показывает значок подсказки у областей с заполненным пояснением. Дальнейшие правки обновляют только личный список. [ADR о личных областях](0006-personal-study-areas.md)
