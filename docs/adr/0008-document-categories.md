# ADR 0008. Категории документов

**Статус — принято.** 23 ноября 2026 года.

## Контекст

На приёме врачу нужно различать бланки анализов, протоколы обследований и заключения, когда они находятся в одной подборке.

## Решение

- У документа есть одно поле `category` со значениями `doctor_report`, `examination` и `lab`. Пациент может выбрать или исправить категорию при загрузке и редактировании.
- В архиве, просмотре и таймлайне категория обозначается подписью и отдельной иконкой. Используем фиолетовый акцент для заключений, синий для обследований и бирюзовый для анализов.
- Ранее сохранённые документы получают пустое значение и нейтральную метку «Без категории». Связи документа с предметными областями сохраняются.
- Фильтр по категории применяется на сервере вместе с фильтром по области и поиском. Параметр `category` сохраняется в ссылке архива и при переходе к сравнению. Значение `uncategorized` выбирает документы без категории.

## Последствия

Один бланк может иметь категорию «Анализ» и быть связан с несколькими предметными областями. Старые записи доступны для просмотра и ручной классификации сразу после обновления.
